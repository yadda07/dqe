Vue d'ensemble

DQE Chargeur est un plugin QGIS professionnel qui automatise la generation des Devis Quantitatif Estimatif pour les projets d'infrastructure fibre optique. Il permet de generer des rapports Excel structures, de visualiser les donnees sur carte, et d'archiver les validations pour une tracabilite complete.

EXE

DQE EXE - Quantitatifs Execution

Le module DQE EXE integre les quantitatifs projet avec le Genie Civil. Il ajoute tranchees, chambres, poteaux et alveoles aux donnees de base.

Difference avec DQE PRO

DQE EXE utilise dqe_exe() au lieu de dqe2() et inclut les elements de genie civil (infrastructure physique).

Tranchees

Traditionnelle, micro-tranchee sous chaussee ou trottoir

Chambres

L3C, L3T et autres types avec comptage par materiau

Poteaux RAUV

Support aerien avec comptage par concessionnaire

Alveoles

PVC 42/45, PEHD 33/40 avec calcul automatique des longueurs

PGC

DQE PGC - Attribution Gestionnaire & Redevances

Le module DQE PGC gere l'attribution des infrastructures aux gestionnaires (concessionnaires de voirie) via un algorithme avance et calcule les redevances associees. Deux modes sont disponibles pour repondre a differents besoins.

Mode Gestionnaire (Recommande)

  • Calcul precis par algorithme de proximite
  • Couche editable dans QGIS
  • Corrections manuelles possibles
  • Regeneration Excel apres modifications
  • Resultats optimises et verifiables

Mode Direct (Rapide)

  • Traitement sans intervention
  • Donnees existantes uniquement
  • Export Excel automatique
  • Pas de correction possible
  • Ideal pour validation rapide

Calcul des Redevances

La fonction gc_exe.redevance_table() genere dynamiquement une table de redevances par concessionnaire selon le type d'infrastructure detecte.

Calcul des redevances par type d'infrastructure
Type Infrastructure Colonnes Generees Calcul
Aerienne Poteaux, Aerien (ml) SUM(nb_pot_ac), SUM(long)
Souterraine Colonnes dynamiques par cm_compo nb_alveoles x long_plan
Mixte Poteaux + Aerien + Alveoles FULL OUTER JOIN des deux
Workflow Mode Gestionnaire
  1. Execution DQE PGC → Chargement couche gestionnaire editable
  2. Modifications → Corriger cm_gest_do dans QGIS (transfert segments)
  3. Regeneration → Bouton "Regenerer Excel" recalcule les redevances
  4. Validation → Archivage des donnees finales dans dqe.dqejson
