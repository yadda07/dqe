DQE Chargeur

Plugin QGIS pour la generation automatisee de Devis Quantitatifs Estimatifs.
Deploiement fibre optique — Auvergne Numerique — DEVTEAM NGE.

Quatre modules, un point d'entree. Le plugin interroge PostgreSQL, construit des couches QGIS georeferencees en EPSG:2154, produit les fichiers Excel depuis des templates metier, et archive les resultats en JSONB.

Prerequis — QGIS 3.28+, PostgreSQL avec schemas rip_avg_nge gc_exe dqe, packages Python psycopg2 pandas openpyxl.

Pipeline

Architecture

Cinq couches. Dependances vers le bas. Chaque module UI lance son propre QThread via BaseDQETab. Services partages et stateless.

Connexion DB via SimpleConnectionPool. Acces par properties publiques is_connected et config. Noms dynamiques via psycopg2.sql.Identifier.

Dependances entre modules

DQE PRO

Quantitatifs projet. Transport TP pour le backbone, Distribution DP pour le deploiement client avec decoupe automatique des cables.

Cables optiques

6 a 720 FO. Aerien, facade, conduite. Cables decoupes auto pour Distribution via fddcpi2().

BPE, PA, PBO

Boites de protection, points d'acces. Quantites par type et mode de pose.

SRO et Prises

Points de raccordement, comptage DTR/RAD.

Archivage

Resultats SQL + FeatureCollections WKT dans dqe.dqejson.

Flux PRO

Comment fonctionne la decoupe

Les cables Distribution sont segmentes par la fonction SQL fddcpi2(). Chaque segment recoit une capacite normalisee et un mode de pose. Le plugin cree ensuite des couches QGIS par combinaison posemode/capacite.

DQE EXE

EXE = PRO + Genie Civil. dqe_exe() appelle dqe2() puis ajoute tranchees, chambres, poteaux, alveoles via jointures LATERAL sur gc_exe.

Tranchees

Traditionnelle, micro-tranchee, forage dirige, encorbellement.

Chambres

L3C, L3T... Comptage GROUP BY inf_mat.

Poteaux RAUV

Comptage nb_pot_ac par concessionnaire.

Alveoles

PVC 42/45, PEHD 33/40. Section dynamique Excel.

Filtrage blocage RAN

Illustration du filtrage selon le parametre p_blocage. Les elements avec blocage_ran=true sont separes des elements travaux.

Infrastructure mixte

Quand un parcours contient des parties aeriennes (cm_typ_imp='0') ET souterraines ('7'), la detection est automatique.

DQE PGC

Attribution des infrastructures aux gestionnaires de voirie, puis calcul des redevances.

Mode Gestionnaire

Couche editable QGIS. Corrections manuelles de cm_gest_do. Regeneration Excel apres modifs.

Mode Direct

Traitement auto complet. Export Excel immediat. Pas de couche gestionnaire.

Algorithme gestionnaire()

Comment fonctionne l'attribution

Illustration : un troncon de cheminement (cable enterre) longe deux routes. L'algorithme segmente le troncon tous les 2m, puis pour chaque point mesure la distance et l'angle vers les routes voisines dans un buffer de 50m.

Types d'infrastructure

DQE Recover

Consultation et regeneration des DQE valides depuis dqe.dqejson. Acces direct sans QThread.

Recherche

Filtrage type + SRO. Limite 30.

Apercu HTML

Watermark ARCHIVE. Worker async.

Regenerer Excel

Depuis donnees archivees.

Recreer couches

Via dqe_recover(). En dev.

Les boutons d'action sont desactives. Seuls recherche et apercu HTML fonctionnent.

Modules

4 modules accessibles via un unique QTabWidget. Chaque module herite de BaseDQETab pour la gestion thread et progress.

Couches

Dependances strictement descendantes. Aucune couche basse n'importe de couche haute.

EXE = PRO + GC

6 codes projet : TE, DE, TT, DT, TB, DB. Parametre p_blocage pour filtrage RAN.
